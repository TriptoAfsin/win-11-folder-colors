# AGENTS.md: win11-folder-colors

Recolors Windows 11 folder icons system-wide by patching icon groups in
`C:\Windows\SystemResources\imageres.dll.mun`. Content thumbnails keep working
(desktop.ini custom icons would turn them off). See README.md for user docs.

## Layout
- `folder_colors.py`: read groups (pefile), recolor (numpy), write .ico, patch a copy with Resource Hacker, export PNG/ICO + the palette sheet.
- `apply.ps1`: self-elevating swap into SystemResources (takeown, rename live to `.old`, copy new, restore TrustedInstaller owner/ACL, clear icon + thumb caches). `apply.cmd` / `restore.cmd` are double-click wrappers.
- `setup.ps1` / `setup.cmd`: pip installs `requirements.txt` and downloads the full Resource Hacker ZIP into `tools/ResourceHacker/` (unsigned, that's normal). `apply.ps1` calls it if RH is missing.
- `backup/imageres.dll.mun.original`: pristine stock file, gitignored. **Never delete or overwrite it by hand.**
- `state.json`: hash of the file we last installed. It tells a Windows update apart from our own patch.
- `icons/<color>/`, `docs/all-colors.png`, `preview.png`: generated by `python folder_colors.py export`. `preview.png` at the root is there so the folder's own Explorer thumbnail shows the palettes.
- `docs/poster.png`: launch poster (source: `U:\Random Projects\Win11 Folder Colors Launch Post\poster.html`, rendered with Playwright at 1080x1350 @2x). `docs/explorer-mockup.png`: Explorer-style mockup.

## Never commit
- `backup/`, `state.json`, `apply.log`: machine-specific.
- `icons/`: recolored Microsoft artwork, generated per user.
- `tools/`: Resource Hacker's licence allows redistribution only as its complete ZIP.

## Facts verified on this machine (build 26300)
- Groups used: 3, 4 (closed), 5 (back), 6 (front), 162 (paper). Each has sizes 256, 64, 48, 40, 32, 24, 20, 16, language 1033. 256 is PNG, the rest are 32-bit DIB.
- Win32 `UpdateResource` fails on `.mun` with ERROR_NOT_SUPPORTED (50). Use Resource Hacker `-action addoverwrite -mask ICONGROUP,<id>,1033`.
- Resource Hacker `-log` output is UTF-16LE **without** a BOM, and success is the line `Success!`.
- Admins have only RX on `SystemResources`. The swap needs takeown on the dir and the file, and the script restores both afterwards (`icacls /save` + `/restore`, `/setowner "NT SERVICE\TrustedInstaller"`).
- `U:` is a local disk, so the elevated process can see it.

## Rules
- Always recolor from `backup/...original`, never from the live system file (it may already be patched).
- Recolor touches only amber pixels (hue 20-70°, sat > 0.15) so the white paper and shadows stay as they are.
- Restart Explorer from the **un-elevated** parent. Starting it from the elevated child gives you an admin shell.
- Test patches on a temp copy before any swap: re-read it with `load_groups` and load it with `LoadLibraryEx(LOAD_LIBRARY_AS_IMAGE_RESOURCE|DATAFILE)` + `LoadImage`.
- Adding a color means changing `PALETTES` (py) **and** `$colors` (ps1).
- Commits use Conventional Commits with a scope, e.g. `feat(apply): ...`, `fix(recolor): ...`, `docs(readme): ...`, `chore: ...`. Use one logical change per commit.

## Known issues
- `icacls /setowner "NT SERVICE\TrustedInstaller"` did not take on the first real run (owner stayed BUILTIN\Administrators, DACL correct). Its output now goes to `apply.log`, so check there after the next run.
